# 💸 App de Organização de Finanças Pessoais Amigável com Vibe Coding

## 💻 PRD refinado através do Copilot Web:

```
# PRD - Aplicativo de Organização de Finanças Pessoais

## Contexto
Criar um aplicativo de Organização de Finanças Pessoais que funcione por meio de conversas com o usuário.  
O objetivo do aplicativo é facilitar o controle financeiro de forma simples e natural, sem formulários manuais ou planilhas complexas.

## Problema a resolver
Muitas pessoas desistem de controlar seus gastos porque os apps atuais exigem muita entrada manual e pouca personalização.  
Este aplicativo busca resolver isso com uma experiência de conversa e recomendações automáticas de economia.

## Público-Alvo
- Pessoas que querem começar a organizar suas finanças de forma prática e sem complicação, principalmente iniciantes.  
- Jovens adultos que estão começando a lidar com independência financeira.  
- Usuários que já tentaram outros apps mas desistiram pela complexidade.  
- Pessoas com baixa familiaridade digital que precisam de simplicidade.

## Funcionalidades-Chave
1. Registrar gastos via chat em linguagem natural.  
2. Classificar automaticamente as transações.  
3. Definir e acompanhar metas financeiras.  
4. Receber dicas de economia do “Agente Financeiro”.  
5. Visualizar relatórios simples e personalizados.  
6. Notificações inteligentes (lembretes e alertas de metas).  
7. Personalização da linguagem (formal/informal).

## Princípio de Design Universal
A solução será construída com base em Design Universal, garantindo que o aplicativo ofereça uma experiência acessível, intuitiva e inclusiva para o maior número possível de pessoas — independentemente de idade, nível de alfabetização digital, limitações físicas ou cognitivas.

### Diretrizes
- Interface clara e legível seguindo as regras do Material Design 3 do Google.  
- Navegação simples e sem sobrecarga de informações.  
- Compatibilidade com leitores de tela e comandos por voz.  
- Feedbacks visuais e auditivos.  
- Contraste adequado de cores e tipografia acessível.  
- Suporte multilíngue (inicialmente português, com expansão futura).  
- Testes com usuários reais de diferentes perfis para validar inclusão.

## Entregável da IA
Gerar um plano de MVP com:
- Principais telas (Boas-vindas, Chat Financeiro, Metas, Relatórios, Configurações).  
- Recursos necessários (NLP, classificação automática, banco de dados local, motor de relatórios, agente financeiro, design responsivo).  
- Esboço de validação inicial (testes com usuários, métricas de sucesso, feedback qualitativo, iteração rápida).


```

## Em resumo, o app criado consegue organizar de forma consistência e fácil de entender e visualizar informações financeiras como gastos e metas;

### INTERFACE 

- Interface inspirada no Material Design 3 do Google: simples e moderno.
- Abas organizam o aplicativo em seções de chat, metas, gastos etc.

### CONTA DE USUÁRIO

- Usuário pode criar uma conta para manter armazenado suas informações financeiras.
- Acesso onde e quando quiser.

### CHAT INTELIGENTE

- Assistente financeiro através de chat-bot inteligente.
- Tira dúvidas e organiza informações financeiras de forma simplificada.

### RESUMOS FINANCEIROS

- Resumos financeiros através de gráficos categorizados de forma simples.
- Fácil entendimento dos gastos e investimentos financeiros.
